# Nodus Draw: desktop releases

This repository holds the downloads of the **Nodus Draw desktop application**
for Windows and Linux, and nothing else: there is no source code here.

Nodus Draw is a vector technical drawing application in the style of
CorelDRAW: flowcharts, circuit diagrams, timing diagrams, dimensions,
symbols, and reading and writing SVG, PDF, DXF, Visio and CorelDRAW files.

- **Use it in your browser**, with nothing to install:
  <https://nodus.cgtk.co.uk>
- **About Nodus Draw**, with pictures of what it does:
  <https://www.cgtk.co.uk/software/nodus>
- **User guide:** <https://www.cgtk.co.uk/software/nodus/docs>

## Downloads

The latest version is on the
[releases page](https://github.com/abudden/nodus-releases/releases/latest).

| File | For |
| --- | --- |
| `Nodus-Draw-Setup-…exe` | Windows: installs Nodus Draw for you (no administrator rights needed); updates itself |
| `Nodus-Draw-…-portable.exe` | Windows: runs without installing |
| `Nodus-Draw-…-win-x64.zip` | Windows: the same, to unzip anywhere (run `nodus.exe`) |
| `Nodus-Draw-…-linux-x86_64.AppImage` | Linux: make it executable and run it; updates itself |
| `Nodus-Draw-…-linux-amd64.deb` | Debian, Ubuntu and their relatives |

The downloads are not yet signed, so Windows may say it "protected your PC"
from an unrecognised app: choose **More info**, then **Run anyway**. There is
no macOS version; on a Mac, use Nodus Draw in Chrome.

The `latest.yml` and `latest-linux.yml` files in each release are what the
application reads to find out whether a newer version is available.

See [Installing the desktop application](https://www.cgtk.co.uk/software/nodus/docs/installing)
in the user guide for more.
